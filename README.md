# Practice Route

一个围绕验收任务安排练习的 Codex 技能。先确定你最终要独立完成什么，再用短练习找出当前卡点，倒推接下来值得花时间的几步。每轮作答都可以改变路线。

| 你要做的事 | 路线怎么安排 |
| --- | --- |
| 备考 | 用考纲和题型确定范围，把练习、限时验证和错因复测排进可用时段。 |
| 学做一个项目 | 用可提交的产物确定终点，从样例、边界条件和测试倒推必要技能。 |

把 `skills/practice-route` 整个目录放进 Codex 可发现的技能目录，然后在对话里调用 `$practice-route`。

- `$practice-route 我十天后考概率论，每天有 40 分钟。帮我排一份能随作答调整的计划。`
- `$practice-route 我能写 Python 循环，想学会清洗 CSV。先给我一个能看出卡点的小任务。`
- `切到检查者，先看我的过程。给我一个提示，等我自己改。`

例如，CSV 练习的终点可以是独立处理一份含缺值和重复记录的新文件，并说明取舍。如果第一次作答显示你已经会读文件，下一轮就直接练缺值处理。随后换一份输入做延迟验证。

## 方法来源

规划设计受 Nick Saraev 视频中目标访谈、学习地图、分段检验和独立重做等方法启发。这个项目将这些方法组织成以验收任务、练习时段和作答证据驱动的计划。 [原视频](https://www.youtube.com/watch?v=FSXHk4hMrY8)
